== Installation

To use this extension, add the `io.quarkiverse.logbook:quarkus-logbook` dependency to your build file.

With Maven, add the following to your `pom.xml`:

[source,xml,subs=attributes+]
----
<dependency>
    <groupId>io.quarkiverse.logbook</groupId>
    <artifactId>quarkus-logbook</artifactId>
    <version>{project-version}</version>
</dependency>
----

With Gradle, add the following to your `build.gradle`:

[source,gradle,subs=attributes+]
----
implementation("io.quarkiverse.logbook:quarkus-logbook:{project-version}")
----
